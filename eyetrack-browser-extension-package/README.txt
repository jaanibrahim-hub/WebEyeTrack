======================================================
           👁️ EYETRACK BROWSER EXTENSION 👁️
======================================================

🚀 QUICK INSTALL:

1. Open Chrome → chrome://extensions/
2. Turn ON "Developer mode" 
3. Click "Load unpacked" → Select THIS folder
4. Click the EyeTrack icon in toolbar!

======================================================

📖 WHAT THIS DOES:

✅ Eye tracking simulation (mouse-based demo)
✅ Blink-to-click functionality (spacebar demo)  
✅ Gaze cursor overlay
✅ Accessibility features
✅ Privacy-focused (local processing)

======================================================

🎮 DEMO CONTROLS:

• Move mouse = Simulate gaze
• Press spacebar twice = Simulate blink-click
• Watch for cyan gaze cursor
• Use extension popup for settings

======================================================

📋 REQUIREMENTS:

• Google Chrome or Chromium-based browser
• Developer mode enabled in extensions
• Camera permission (for future real eye tracking)

======================================================

🆘 SUPPORT:

Read INSTALL.md for detailed instructions
Check extension popup for help and settings
