# 👁️ EyeTrack Browser Extension - Installation Guide

## 🚀 Quick Install (3 Steps)

### Step 1: Download & Extract
- Download this folder to your computer
- Extract if it's in a zip file

### Step 2: Open Chrome Extensions
1. Open Google Chrome
2. Go to `chrome://extensions/`
3. Turn ON "Developer mode" (toggle in top-right corner)

### Step 3: Load Extension
1. Click "Load unpacked" button
2. Select this entire folder (`eyetrack-browser-extension-package`)
3. Click "Select Folder"

## ✅ You're Ready!

The EyeTrack extension should now appear in your extensions list and toolbar!

## 🎮 How to Use

### Getting Started
1. **Click the EyeTrack icon** in your browser toolbar (👁️)
2. **Click "Start Tracking"** in the popup
3. **Allow camera access** when prompted
4. You'll see a status indicator saying "Demo Mode"

### Demo Controls
- **Move your mouse** → Simulates gaze tracking
- **Press spacebar twice quickly** → Simulates double blink (click)
- **Watch the cyan cursor** → Shows where you're "looking"

### Settings
- **Quick Settings**: Click the extension icon for basic controls
- **Advanced Settings**: Click "⚙️ Advanced Settings" for full configuration

## 🎯 What This Does

This extension demonstrates **eye tracking + blink-to-click** functionality:

- 👁️ **Gaze Cursor**: Visual indicator of where you're looking
- 👆 **Blink-to-Click**: Double blink to click elements  
- ⚙️ **Customizable**: Adjust sensitivity, smoothness, etc.
- 🔒 **Privacy**: All processing happens on your device
- 🌐 **Universal**: Works on any website

## 🔧 Troubleshooting

### Extension Not Loading?
- Make sure "Developer mode" is enabled
- Try refreshing the extensions page
- Check that you selected the correct folder

### Camera Permission Issues?
- Click "Allow" when prompted
- Check browser camera settings
- The extension works in demo mode without camera

### Not Working on a Page?
- Refresh the webpage after installing
- Check if the page allows extensions
- Try on a different website
