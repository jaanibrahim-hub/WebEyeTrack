🎮 HOW TO USE (UPDATED):

1. 📂 Install extension (chrome://extensions/ → Load unpacked)
2. 🌐 Navigate to ANY regular website (NOT chrome:// pages)
3. 👁️ Click EyeTrack extension icon
4. ▶️ Click "Start Tracking" 
5. 🖱️ Move mouse to simulate gaze tracking
6. ⌨️ Press spacebar twice quickly to simulate blink-click
7. 👀 Watch for cyan gaze cursor on the page

⚠️ IMPORTANT NOTES:
